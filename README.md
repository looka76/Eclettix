# Eclettix 🎙

Web app per chattare con la voce in tempo reale con musica non stop nelle stanze virtuali.

## Features
- **3 stanze tematiche**: The Lounge (Jazz), Electronic Pulse, Chill Zone
- **Voice chat P2P** via WebRTC — nessun server relay necessario
- **Musica in streaming** sincronizzata per tutti nella stanza
- **Chat testuale** in tempo reale
- **Controllo volume** e pausa musica individuali

## Avvio rapido

```bash
npm install
npm start
```

Apri `http://localhost:3000`

## Stack
- **Backend**: Node.js, Express, Socket.io
- **Frontend**: HTML/CSS/JS vanilla, WebRTC
- **Signaling**: Socket.io
