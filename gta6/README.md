# Atlante di Leonida — guida non ufficiale a GTA VI

Web app in italiano, ottimizzata per iPhone e iPad (installabile sulla schermata Home, funziona offline dopo la prima apertura).

- **Mappa interattiva** di Leonida (illustrazione schematica originale, posizioni indicative): pan, pinch-zoom, filtri, segnaposti personali
- **Trucchi** con le sequenze del D-pad e i requisiti di sblocco
- **Relitti di Kenton**, luoghi segreti ed easter egg, con checklist
- **Collezionabili** con contatori, **armi uniche** e **veicoli rari**
- **Guida**: primi passi, soldi, capitoli (con protezione spoiler), regioni, attività
- Ricerca globale; progressi salvati sul dispositivo

## File
- `app.html` — sorgente della pagina (anche versione pubblicata come Artifact)
- `index.html` — documento completo generato con `node build.mjs`
- `manifest.webmanifest`, `sw.js`, icone — per l'installazione come PWA

## Pubblicare
Serve un hosting HTTPS statico (es. GitHub Pages sulla cartella `gta6/`). Poi da Safari: Condividi → Aggiungi alla schermata Home.

Guida amatoriale non affiliata a Rockstar Games / Take-Two.
